# CSMap

[中文说明](README_zh.md)

**Cell-type-aware global assignment of single-cell transcriptomes to spatial transcriptomic spots.**

This repository contains the dense CSMap implementation and the analysis code associated with the manuscript's final Figures 1–5. CSMap expands spot capacities into slots with cell-type labels, combines expression costs with a finite cell-type mismatch penalty, and solves a global linear assignment problem using LAPJV. Finite penalties allow expression evidence to override the composition prior while retaining the prescribed spot capacities.

This is a manuscript reproducibility repository. It includes a runnable synthetic example, the saved benchmark assignments and plotting inputs, and scripts for the selected MOB ablation and gastric analyses. It does not contain the thesis, manuscript drafts, patent materials, unrelated tissue experiments, or experimental sparse solvers.

## Installation and quick start

Tested with Python 3.12 on macOS. Run the following commands from the repository root:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python analysis/demo.py
python analysis/check_benchmarks.py
python analysis/test_original_quota_fix.py
```

The demo creates synthetic input matrices and maps 24 cells to eight spots with three cells per spot. Outputs are written to `results/demo/`. The benchmark check recomputes 60 scores across the three settings and four methods from the included assignments and compares them with the manuscript tables.

Large biological datasets are **not** needed for these checks or for redrawing Figures 2–5. Full mapping runs have substantially higher memory requirements: the original solver constructs a dense N × N cost matrix, where N is the number of assigned instances.

### Metric definitions and interpretation

- **CMR:** fraction of assigned instances mapped to their known source spot.
- **CU:** fraction of unique reference cells used at least once.
- **WCMR:** spot precision weighted by the true cell count of each spot, as implemented in `analysis/metrics.py`.
- **WRR:** spot recall weighted by the true cell count of each spot.
- **OP-Score:** CMR × CU.
- **Composition TV:** half the sum of absolute type-fraction differences per spot, averaged over spots.
- **SMLE:** Figure 2 uses the preserved historical distributions in `data/figure2/historical_*_smle.csv`. The spot-center distances that can be recalculated from the saved mappings are a different evaluation record and must not silently replace these distributions. The original SMLE records do not provide complete per-cell traceability for harmonizing duplicate and unmapped-cell handling.

The two cerebellum settings share reference cells. MOB composition priors are derived from simulation truth. Gastric sections are descriptive examples selected after analysis, and held-out-marker agreement is not a validation of true single-cell coordinates or clinical utility. Spatial smoothing is used for display; the paired marker correlations use unsmoothed mapped fractions.

## Map a new dataset

```bash
python analysis/run_mapping.py \
  --sc inputs/mydata/sc.csv \
  --st inputs/mydata/st.csv \
  --cell-types inputs/mydata/types.csv \
  --coordinates inputs/mydata/coordinates.csv \
  --fractions inputs/mydata/fractions.tsv \
  --weights inputs/mydata/weights.tsv \
  --capacities inputs/mydata/capacities.tsv \
  --penalty 1e-6 --seed 1 --quota-guard \
  --out results/mydata
```

| Input | Layout |
| --- | --- |
| `--sc` | Genes × reference cells; first column contains gene identifiers |
| `--st` | Genes × spatial spots; first column contains gene identifiers |
| `--cell-types` | Cell identifier index and one cell-type column |
| `--coordinates` | Spot identifier index and two coordinate columns |
| `--fractions` | Tab-separated spot × cell-type prior fractions; rows sum to one |
| `--weights` | Tab-separated single row of global cell-type fractions |
| `--capacities` | Optional tab-separated spot identifier index and integer `n_cells` column |

The synthetic files under `results/demo/inputs/` provide a complete working example. Matrix Market input is also supported with sibling `genes.tsv` and `barcodes.tsv` files, as prepared by `run_gastric.py`. The bundled scanpy compatibility reader does not implement `read_visium`; prepare matrices explicitly.

Omitting `--penalty` retains the original adaptive penalty rule. `--penalty 0` gives an expression-only assignment. Penalty magnitudes depend on the original expression-cost scale. `--quota-guard` enables the negative-quota repair used for the gastric analyses. The output assignment CSV records `UniqueCID`, `OriginalCID`, `CellType` and `SpotID`, preserving the distinction between sampled instances and original reference cells.

## Rerun the MOB analysis

Place the study's prepared MOB inputs in `inputs/mob/`:

```text
MOBsc.csv
MOBst.csv
MOBcelltype.csv
MOBstxy.csv
```

Ground-truth labels, spot coordinates and the saved truth-derived prior are included under `analysis/data/`. Their legacy filenames `Seurat_cellfracs.txt` and `Seurat_weights.txt` are input interface names; these files do **not** establish that Seurat was rerun.

```bash
python analysis/run_figure4_improved.py --datasets mob --noise-lambda 1e-6
python analysis/run_figure4_improved.py --datasets mob --noise-lambda 3
python analysis/run_figure5_robustness.py
python analysis/paired_analysis.py --mob-only
```

The robustness runner's resource measurement uses macOS `/usr/bin/time -l`. It is not a hardware-normalized runtime benchmark. Outputs are written under `analysis/output/`; the frozen manuscript tables under `data/` are not automatically overwritten.

`prepare_mob_data.py` can regenerate truth-derived priors when the original paired CARD simulation RData file specified in `analysis/config.py` is available. The large expression matrices and this RData archive are not distributed here; the saved tables support metric auditing and figure reconstruction without them. The optional cerebellum run configurations likewise require the prepared simulation matrices under `inputs/cerebellum/test1/` and `test2/`.

## Rerun the gastric analysis

The included downloader retrieves public GEO files for spatial sections D02T1, D18T2 and D24T2 and reference donors D03T, D04T and D05T:

```bash
python analysis/download_gastric_validation_data.py
python analysis/prepare_gastric_biology.py
python analysis/run_gastric.py
python analysis/paired_analysis.py --gastric-only
python analysis/prepare_figure5_source.py
```

The preparation defines 11 marker-based cell types, constructs a composition prior from standardized marker-module scores, and estimates capacities from histology. Evaluation markers and LAR markers are held out from the mapping gene pool and prior construction. The original dense CSMap implementation is used for both penalty conditions, with matched inputs and seed 2026. The paired analysis verifies instance identity, capacities and input hashes before comparing conditions.

Fresh numerical results are saved under `analysis/output/`. Regenerated Figure 5 spatial inputs are saved under `results/figure5_source/`; the included frozen inputs under `data/figure5/` remain the defaults for the final manuscript drawing. To visualize a fresh analysis, explicitly replace the corresponding plotting inputs after comparing the audits; `gastric_paired_heldout.csv` corresponds to `marker_correlations_all33.csv`.

## Data sources

- Gastric cancer atlas: GEO [GSE270678](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE270678) and [GSE270680](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE270680). Sample identifiers and exact download filenames are listed in `analysis/download_gastric_validation_data.py`.
- Cerebellum reference: GEO [GSE116470](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE116470); spatial data: [SCP354](https://singlecell.broadinstitute.org/single_cell/study/SCP354).
- MOB benchmark: the paired CARD simulation used in the study. The exact local source filename and included derived files are documented in `analysis/config.py` and `provenance/source_files.json`; no new accession is invented for this derived benchmark.

Included tables are derived research outputs; the Figure 5 histology images originate from the public GEO spatial samples. Original data retain their source terms. Raw sequencing files and the full expression matrices are not redistributed in this repository.
